# 🛒 E-Commerce Cart Testing (Selenium + Python)

This project automates the testing of add/remove cart functionality on an e-commerce demo site.

## Features
- Add items to cart
- Remove items from cart
- Verify prices and product details
- HTML test report with pytest-html

## Tools
- Selenium WebDriver
- PyTest
- pytest-html

## Run Tests
```bash
pytest tests/ --html=reports/report.html
